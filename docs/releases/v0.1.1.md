Two fixes found in use, each with the test that would have caught it.

- A preset picked again while already current left the chain as it had been
  edited on the FX page, while the page showed the preset's settings. The
  page now hands the preset's chain to the audio thread itself.
- A host that changed sample rate after loading kept the strings tuned for
  the first rate: middle C at 240 Hz after a move from 48 to 44.1 kHz. The
  string prototypes are rebuilt with the rate.

Also: every window and test builds without a warning; NOTICE names what the
repository carries from others; README says how to install the bundles and
what CPU they need.
